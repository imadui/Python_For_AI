# Course Map

Start with `exercises/00_diagnostic.py`.

Then follow:

1. [Core syntax, types, f-strings](sessions/01_core.md)
2. [Lists + dictionaries](sessions/02_lists_dicts.md)
3. [Conditions, loops, comprehensions](sessions/03_flow.md)
4. [Functions + type hints](sessions/04_functions_typing.md)
5. [Exceptions + files + JSON](sessions/05_errors_files_json.md)
6. [Modules + classes + composition](sessions/06_modules_oop.md)
7. [HTTP APIs + JSON responses](sessions/07_http_api.md)
8. [pytest + final challenge](sessions/08_testing_final.md)

The goal is not to complete every possible Python topic. The goal is to reach the point where Pydantic, FastAPI, LLM APIs, RAG, and agent code no longer feel blocked by Python fundamentals.
